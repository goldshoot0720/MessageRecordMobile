MessageRecord 1.0.3 — 可搜尋已儲存的通知。

- 首頁新增「搜尋通知」，可用 App 名稱、套件名稱、通知標題或內容尋找全部紀錄。
- 應用程式詳情頁新增搜尋入口，結果只限該應用程式的通知。
- 可切換全部、已攔截或已允許；結果依通知時間由新到舊排序，點選可開啟通知詳情。
- 搜尋文字會在從詳情返回時保留；空白、無結果與暫時讀取失敗都有明確提示。
- `%`、`_`、引號等特殊字元一律視為文字，不會擴大搜尋範圍或改變資料庫查詢。

安裝：Android 8.0 以上，套件 ID `com.notiguard.debug`，versionCode 4，可直接覆蓋 v1.0.2 預覽版。此版本仍為 Debug 簽署預覽 APK。

驗證：17 項 Room／通知服務回歸測試、SQLite 資料遷移測試、assembleDebug、lintDebug（0 errors，50 warnings）、APK 簽章一致性及搜尋畫面實機檢視均通過。新版模擬器連線在最後驗證階段不可用；已不影響已完成的建置與測試結果。
