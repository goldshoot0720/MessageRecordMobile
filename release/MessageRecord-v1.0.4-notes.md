MessageRecord 1.0.4 — 介面改版與獨立搜尋頁。

- 全套圖示改為自繪向量路徑（24dp、1.7 線寬），畫面統一鋪漸層底、卡片與分段篩選。
- 搜尋改為獨立頁面：從首頁或 App 詳情進入，可用 App 名稱、套件名稱、通知標題或內容尋找。
- 進入搜尋頁會自動聚焦輸入框並叫出鍵盤，不必再多點一次。
- 搜尋框提示改為「App 名稱、標題或內容」；先前被標籤蓋住，未聚焦時看不到。
- 新增匯出：App 詳情頁右上「⋯」可將該 App 的紀錄存成跨平台 JSON。
- `%`、`_`、引號等特殊字元一律視為文字，不會擴大搜尋範圍或改變資料庫查詢。

安裝：Android 8.0 以上，套件 ID `com.notiguard.debug`，versionCode 5，可直接覆蓋 v1.0.3 預覽版。此版本仍為 Debug 簽署預覽 APK。

驗證：17 項單元測試 0 失敗、assembleDebug、lintDebug（0 errors），以及模擬器實機走查首頁、統計、App 詳情、通知詳情與搜尋（自動聚焦、輸入、結果、清除）。由 v1.0.3 覆蓋安裝後既有紀錄保留，資料庫未被清空。
