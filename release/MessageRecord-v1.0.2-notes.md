MessageRecord 1.0.2 — 修正通知更新與群組摘要造成的重複紀錄。

- 同一通知的訊息時間與內容未變時，重新發布或更新不再新增紀錄。
- 群組摘要不再另存成訊息；仍依原有開關與規則攔截。
- 保留不同通知識別碼、不同訊息時間或不同內容的紀錄，不只按文字去重。
- MessagingStyle 優先使用訊息時間；缺少來源時間時採保守處理，避免誤合併新訊息。
- 去重結果存於資料庫，監聽服務重啟後仍有效。
- 既有紀錄與設定保留。舊版未保存足夠資訊辨識摘要與更新，因此不自動清除舊重複紀錄。

安裝：Android 8.0 以上，套件 ID com.notiguard.debug，versionCode 3，可直接覆蓋 v1.0.1 預覽版。此版本仍為 Debug 簽署預覽 APK。
